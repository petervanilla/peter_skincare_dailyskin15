# K-beauty demo visuals

The default catalog contains 36 Korean skincare products. These are demo selections, not a live Olive Young inventory. Representative market references: [Olive Young skincare](https://www.oliveyoung.co.kr/store/display/getMCategoryList.do?dispCatNo=10000010001), [Aestura official brand shop](https://brand.amoremall.com/kr/ko/aestura?menuNo=693). Product formulas, stock and packaging should be checked with the brand before production use.

Six generic AI package mockups are saved in `public/products/mockups/` as optimized 640px WebP images. Each curated row maps to a package shape with its `mock` field. These are shared category illustrations, not reproductions of the named products. The cards label them “목업”; detail sheets explicitly distinguish them from real branded packaging. They were generated with the built-in image_gen tool on 2026-09-20, then resized and encoded with Sharp. No remote image requests are needed.

The leaderboard uses seven existing Stitch design portraits from `public/design/12-leaderboard-ranking-*.jpg`, cropped with CSS to fill the avatar. They represent demo participants, not uploaded user photos. The demo account uses the existing `10-progress-day7-1.jpg` profile portrait; personal accounts keep their own photo or initial.
